# Payment Dispute Workflow API - Guided Build

A learning-first backend portfolio project based on debit-dispute workflows. This repository intentionally contains **no completed business logic**. Build each milestone yourself and use the acceptance criteria to verify your work.

## Target stack
Python 3.12, FastAPI, PostgreSQL, SQLAlchemy 2.x, Pydantic, pytest, Alembic, JWT authentication, Docker, GitHub Actions.

## Learning rule
Do not copy a finished implementation. Complete one issue at a time, commit your work, run tests, and explain each design choice in your own words.

## Milestones
1. Domain model and transition rules
2. In-memory service layer
3. FastAPI CRUD endpoints
4. PostgreSQL and SQLAlchemy
5. Authentication and authorization
6. Filtering and pagination
7. Automated testing
8. Docker and CI
9. AI dispute classifier
10. Document analyzer and policy RAG assistant

See `ROADMAP.md`, `REQUIREMENTS.md`, and `LEARNING_CHECKPOINTS.md`.
